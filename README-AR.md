# אתר תוצאות מבחן – אקדמיזציה בתיכון בשפה העברית

## ما الموجود؟
موقع GitHub Pages يعرض **שם התלמיד/ה، מספר זהות، תוצאה** فقط، والنتيجة إحدى الحالتين: `בתכנית` أو `לא בתכנית` (دون علامات رقمية أو B1).
يحتوي الموقع على **42 سجلًا مشفرًا كل واحد على حدة** باستخدام AES-256-GCM. لا يحتاج الموقع إلى Cloudflare، أو قواعد بيانات، أو حسابات أخرى غير GitHub.

## 1) رفع الموقع إلى GitHub
1. فك ضغط ملف ZIP.
2. أنشئ مستودعًا جديدًا عامًا Public في GitHub، أو افتح المستودع السابق.
3. ارفع **مجلد `docs` كله** كما هو من هذا الملف، ليكون مساره `docs/index.html`. وارفع README إن رغبت.
4. إذا كنت تستبدل النسخة القديمة: احذف الملفات القديمة `docs/admin.html` و`docs/assets/admin.js` و`docs/assets/config.js` والمجلد `worker` لأنها لم تعد مستخدمة.
5. من **Settings → Pages** اختر **Deploy from a branch** ثم `main` و`/docs` ثم **Save**.
6. افتح رابط الموقع الذي تعرضه GitHub Pages عبر HTTPS. 

## 2) توزيع الرموز للطلاب
يوجد ملف منفصل **خارج ZIP تمامًا**: `رموز_دخول_الطلاب_سري_42.csv`، يحتوي أسماء الطلاب وأرقام الهويات ونتائجهم ورموزهم الخاصة.
كما يوجد ملف `بطاقات_رموز_الطلاب_للطباعة_سري.html` للطباعة وقصّ البطاقات الفردية.
**لا ترفع أبدًا هذين الملفين إلى GitHub أو إلى أي مجلد من مجلدات الموقع المنشور.** وزّع كل رمز سرًا على الطالب المعني فقط.

## 3) استخدام الطالب
- يدخل رقم الهوية كاملًا كما ورد في القائمة (9 أرقام أو 10 أرقام للطالب الاستثنائي).
- يدخل رمز الدخول الشخصي المخصص له والمكوّن من 20 حرفًا/رقمًا، ويمكن إدخاله مع الشرطات أو بدونها.
- يضغط `הצגת התוצאה` فتظهر له بياناته والنتيجة `בתכנית` أو `לא בתכנית`.

## مهم عن الخصوصية
- ملف `docs/assets/encrypted-results.js` منشور للعامة لكنه يحتوي بيانات مشفرة فقط، ولا يتضمن أسماء الطلاب أو هوياتهم بنص مقروء.
- كل طالب له مفتاح خاص به، ولم تُشفّر القائمة كاملة بمفتاح واحد. المفاتيح مولّدة عشوائيًا وبقوة نحو 100 بت لكل طالب؛ حماية النتائج تعتمد على الحفاظ على سرية الرمز وعدم نشره.
- GitHub Pages **استضافة عامة، وليست نظام دخول متقدمًا**: لا يوجد إلغاء فوري للرموز المسربة، ولا منع محاولات الدخول أو سجلات مراجعة. من يحصل على رمز طالب ورقم هويته يستطيع رؤية نتيجته. إذا ضاع رمز طالب أو تسرب، يجب إعادة تشفير ونشر النسخة المحدثة برمز جديد.
- عند إعادة توليد المشروع من الصفر تتغير **كل** الرموز؛ يجب توزيع الرموز الجديدة على الطلاب.
- يجب مراعاة سياسة المدرسة ومتطلبات الخصوصية قبل النشر.
- لا ترفع ملف Excel الأصلي الذي يتضمن أسماء الطلاب وأرقام الهويات.

## تجربة قبل النشر
يمكن تجربة الموقع من الحاسوب (يفضل متصفح حديث عبر localhost أو GitHub Pages). للاختبار افتح بطاقتك الخاصة بأحد الطلاب من الملف السري، واكتب بياناته. لا تشارك بيانات الطالب ضمن صور أو محادثات عامة.
