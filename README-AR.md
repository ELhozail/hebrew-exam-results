# نتائج امتحان الأكاديمיזציה في الثانوية – اللغة العبرية
## תוצאות המבחן – באקדמיזציה בתיכון בשפה העברית

**الموقع يعرض نتيجة واحدة فقط لكل طالب: `בתכנית` أو `לא בתכנית`. لا توجد علامات رقمية ولا يعرض الموقع B1.**

## محتويات الحزمة
- `docs/` واجهة الطلاب باللغة العبرية، وصفحة إدارة `admin.html`.
- `worker/` خادم Cloudflare Worker وقاعدة D1 الخاصة.
- **لا يحتوي ZIP على ملف بيانات الطلاب**: احتفظ بالـCSV المنفصل بعيدًا عن GitHub.

## رفع الموقع على GitHub Pages
1. ادخل GitHub وأنشئ مستودعًا عامًا مثل `hebrew-exam-results`.
2. ارفع المجلدات بنفس ترتيبها بحيث يكون `docs/index.html` داخل المستودع.
3. Settings → Pages → Deploy from a branch → `main` → `/docs` → Save.
4. افتح رابط الموقع؛ عند عدم إعداد الخادم لا يعمل إلا وضع العرض التجريبي.

## تشغيل البحث الحقيقي بطريقة خاصة
1. افتح Cloudflare وأنشئ حسابًا، وثبّت Node.js على الحاسوب.
2. داخل مجلد `worker` نفّذ:

```sh
npx wrangler login
npx wrangler d1 create hebrew-academization-results
```

3. ضع قيمة `database_id` الناتجة في `worker/wrangler.jsonc` بدل المعرف الافتراضي. اجعل `ALLOWED_ORIGIN` مساويًا لأصل موقع GitHub مثل `https://USERNAME.github.io` (دون مسار المستودع).
4. نفّذ الأوامر من داخل `worker`:

```sh
npx wrangler d1 execute hebrew-academization-results --remote --file=migrations/0001_init.sql
npx wrangler secret put ID_HMAC_KEY
npx wrangler secret put ADMIN_SECRET
npx wrangler deploy
```

اختر قيمتين عشوائيتين طويلتين ومختلفتين للمفتاحين السريين (32 حرفًا أو أكثر). لا ترفع الأسرار إلى GitHub. احتفظ بمفتاح `ID_HMAC_KEY` للاستيراد اللاحق.
5. انسخ رابط Worker الذي ظهر بعد نشره (مثل `https://...workers.dev`) إلى `docs/assets/config.js` ضمن `apiUrl`؛ ثم ارفع الملف المعدّل إلى GitHub.
6. افتح `https://USERNAME.github.io/hebrew-exam-results/admin.html`، وأدخل سر المدير واستورد ملف CSV الخاص (خارج ZIP).

**مهم:** رمز PIN الشخصي مفعل افتراضيًا. الطالب يُدخل رقم هويته كما ورد في ملف المدرسة كاملًا (9 أرقام لمعظم الطلاب، و10 أرقام لحالة واحدة)، مع رمزه الشخصي الخاص ليعرض اسمه ورقم الهوية ونتيجة الاشتراك فقط. عدم توفر الرمز أو تعطيله يضعف الخصوصية؛ رقم الهوية وحده ليس إثباتًا لهوية الطالب.

## ملف الاستيراد (CSV UTF-8)

```csv
student_id,student_name,status,pin
000000000,שם תלמיד לדוגמה,בתכנית,123456
```

القيمة الثالثة هي واحدة من `בתכנית` أو `לא בתכנית`، دون أي `grade` أو `ציון`. المثال ليس بيانات طالب حقيقي، ورقم الهوية في المثال لا يستخدم لطالب فعلي.

للتوافق مع ملفات الاستيراد السابقة، يقبل الخادم قيم `B1` و `NOT_IN_PROGRAM` القديمة داخليًا، لكنها لا تظهر على صفحة الطالب.

إذا استوردت الطلاب مسبقًا إلى قاعدة البيانات السابقة، ستبقى بياناتهم وتعمل الواجهة الجديدة دون استيراد إضافي؛ وإذا أعدت الاستيراد فستُحدّث سجلات الهويات المطابقة فقط. قاعدة البيانات القديمة التي فيها عمود grade تقبل المشروع الجديد لأن العمود يُترك بلا استخدام.

## ملاحظات عن البيانات التي أرسلتها
- ملف CSV الخاص المرفق مع هذه النسخة يحتوي جميع الطلاب الـ42، بمن فيهم حالة واحدة برقم مؤلف من 10 أرقام أقرّت المدرسة بصحته.
- يحتفظ الموقع بالرقم ذي 10 أرقام كما هو دون قصّه أو تغييره، ولا يعرض علامات رقمية.
- أعددنا CSV جديدًا بأربعة أعمدة وحالتي الاشتراك بالعبرية فقط، مع الاحتفاظ برموز الدخول نفسها.
- لا ترفع CSV خاصًا إلى GitHub أو تشاركه في مجموعات عامة.

## رقم الطالب الاستثنائي المكوّن من 10 أرقام
- بعد تأكيد المدرسة أن هذا الرقم مكتوب هكذا بالفعل، يسمح النموذج والخادم والاستيراد بإدخال 9 أو 10 أرقام.
- الأرقام التسعة تخضع لفحص رقم الهوية الإسرائيلي المعتاد؛ الرقم ذو 10 أرقام يُعامل كمعرّف مدرسي كما هو موجود في البيانات، وليس كتأكيد لصحة رقم هوية إسرائيلي رسمي.
- يجب أن يكتب الطالب رقمه كما هو دون حذف أي رقم؛ ويبقى التحقق باستخدام كود PIN الشخصي ساريًا.
- CSV الخاص: `תוצאות_תלמידים_סטטוס_42_פרטי.csv` (منفصل عن حزمة GitHub، ولا يُنشر).
