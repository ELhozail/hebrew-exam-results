# نتائج امتحان الأكادَمة في الثانوية — اللغة العبرية
## תוצאות המבחן – באקדמיזציה בתיכון בשפה העברית

**الموقع جاهز من حيث التصميم والبرمجة، لكنه لا يحتوي على بيانات طلاب حقيقية ولا يعمل للبحث الفعلي قبل تفعيل خادم النتائج وإضافة علامات الطلاب.**

يتضمن المشروع:
- `docs/index.html`: موقع الطالب بالعبرية (GitHub Pages).
- `docs/admin.html`: صفحة المدير لاستيراد CSV.
- `docs/assets/config.js`: ربط موقع GitHub بالخادم.
- `worker/`: خادم Cloudflare Worker وقاعدة بيانات D1 خاصة، لا تُنشر العلامات وأرقام الهويات ضمن GitHub.

## أولًا: انشر التصميم على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub، مثل `hebrew-exam-results`.
2. ارفع الملفات بنفس ترتيب المجلدات، بما فيها `docs` و `worker`.
3. من **Settings → Pages → Build and deployment** اختر **Deploy from a branch**.
4. اختر فرع `main` والمجلد `/docs` ثم **Save**.
5. سيصبح رابط الموقع غالبًا `https://USERNAME.github.io/hebrew-exam-results/`.
6. يمكن فتح الموقع وتجربة زر **הצגת דוגמה**؛ لا توجد بيانات طلاب في GitHub.

## ثانيًا: خادم النتائج الخاص (Cloudflare D1 + Workers)
لا تكفي GitHub Pages وحدها لحفظ علامات الطلاب، لأنها تستضيف ملفات عامة وثابتة. يتطلب البحث الحقيقي خادمًا وقاعدة بيانات منفصلين. يمكنك الاستفادة من الخطط المجانية ضمن حدود الاستخدام.

1. أنشئ حسابًا في Cloudflare وثبّت Node.js على جهازك.
2. افتح Terminal/PowerShell في مجلد `worker` ونفّذ:

```sh
npm install -g wrangler
wrangler login
wrangler d1 create hebrew-academization-results
```

3. انسخ معرّف `database_id` الذي يظهر وضعه في ملف `worker/wrangler.jsonc` بدل `REPLACE_WITH_YOUR_D1_DATABASE_ID`.
4. غيّر `ALLOWED_ORIGIN` إلى **أصل عنوان GitHub دون اسم المستودع**، مثال: `https://YOURNAME.github.io`.
5. نفذ:

```sh
wrangler d1 execute hebrew-academization-results --remote --file=migrations/0001_init.sql
wrangler secret put ID_HMAC_KEY
wrangler secret put ADMIN_SECRET
wrangler deploy
```

استخدم مفتاحين طويلين وعشوائيين مختلفين (يفضّل 32 حرفًا عشوائيًا أو أكثر). **احتفظ بمفتاح `ID_HMAC_KEY`؛ تغييره لاحقًا يجعل كل سجلات الطلاب المحفوظة غير قابلة للبحث حتى تعيد الاستيراد.** لا ترفع الأسرار إلى GitHub.

6. انسخ رابط Worker الفعلي، مثل `https://hebrew-academization-results-api.<your-subdomain>.workers.dev` إلى `docs/assets/config.js` داخل `apiUrl`.
7. ارفع تعديل `config.js` إلى GitHub. الآن يمكن للطلاب البحث بعد رفع البيانات.

## ثالثًا: ملف العلامات والاستيراد
في Excel أنشئ الأعمدة بالترتيب التالي:

| student_id | student_name | grade | status | pin |
|---|---|---|---|---|
| رقم هوية (9 أرقام) | اسم بالعبرية | عدد 0–100 | B1 أو NOT_IN_PROGRAM | رمز خاص بالطالب |

**لا ترفع هذا الملف إلى GitHub.** احتفظ بالهويات كنص حتى لا تضيع الأصفار الأولى. صدّر Excel كـ **CSV UTF-8**؛ عند فتحه في Notepad ينبغي أن تظهر فاصلة `,` بين الخانات.

اذهب إلى موقعك على `.../admin.html`، أدخل قيمة `ADMIN_SECRET` وحدد ملف CSV واضغط على **ייבוא התוצאות**. يتم تحديث الملفات على دفعات بحد أقصى 25 سجلًا في الطلب. الاستيراد الجديد يعدّل الهويات المطابقة؛ ولا يحذف الطلاب القدامى تلقائيًا.

## مهم جدًا: خصوصية علامات الطلاب
**إدخال رقم الهوية وحده لا يثبت أن الشخص هو صاحب الهوية.** أي شخص يعرف رقم هوية طالب قد يستطيع كشف علامته. لذلك يأتي الإعداد الآمن الافتراضي مع **رمز PIN شخصي لكل طالب** (عمود `pin` و `REQUIRE_PIN: "true"`). يجب توزيع رموز PIN بوسيلة خاصة والتحقق من هوية الطالب قبل إعطائها. لا تشارك CSV أو الأكواد مع الطلاب.

يمكن تقنيًا تعطيل الكود بتغيير `REQUIRE_PIN` في `worker/wrangler.jsonc` إلى `"false"`، وكذلك `requirePin: false` في `docs/assets/config.js` وإعادة النشر، **لكن لا يُنصح بذلك إطلاقًا لعلامات طلاب حقيقية**. تحديد المعدل إلى 12 محاولة لكل IP لكل 15 دقيقة لا يمنع انتحال شخصية الطالب إذا كان رقم هويته معروفًا. فكّر بموافقة إدارة المدرسة ومسؤول الخصوصية قبل النشر.

لا يُخزَّن رقم الهوية بصيغته الأصلية في D1؛ بل مشتق HMAC سري. عند العرض يكتب الموقع الرقم الذي أدخله الطالب. ولا تُرسل الهوية ضمن عنوان URL. الأسماء والدرجات مخزنة في قاعدة D1 الخاصة، وليس في GitHub.

## خيارات تخصيص
- ألوان الموقع في `docs/assets/style.css`.
- النصوص بالعبرية في `docs/index.html`.
- علامة الطالب من 100، وحالة الطالب من إحدى قيمتين: `בתכנית B1` / `לא בתכנית`.
- إذا أردت إظهار العلامة فقط أو تغييرها إلى فئة دون رقم، يمكن تعديل الواجهة والخادم.
